现状

为什么看着不规整

不是字号问题，是「没有骨架」：四个区块只靠虚线分隔，标题和正文同一个灰阶；步骤表没有表头，每行都重复一个「手写」；右栏路径折成三行，编辑铅笔被挤到下一行；「未找到可复用封装」占掉一整块。读起来像一份 Markdown 转出来的草稿，不像一份要签字确认的东西。

具体问题（按视觉顺序） 1. 虚线 + 无表头，区块之间没有容器，视线落不到边界
2. 「手写」×7 是噪声：全部手写时这个信息属于表头，不属于每一行
3. 项目风格是三行 label:value，import 那行折行后和说明糊在一起
4. 右栏 330px 里塞了路径、建议、意见、按钮，四件事互相挤
5. 空状态（0 条封装 / 0 条意见）各占一块版面

03

点「按此执行」之后

现在点了执行，任务书停在原地、按钮转圈，最长要等两三分钟，中间只有面板底部一条 6px 的进度条——用户不知道是在写、在校验、还是在真跑。后端其实一直在报阶段（prepare / detect / snapshot / writing / check / validate / repair / run / record），只是前端没接出来。三个方向都是把这些阶段摊开：A 给了运行 / 完成 / 失败三种状态，B 不开第二层窗口，C 是给调脚本的人看的日志流。
