## 定位降级：不唯一不再阻断生成（第一批）

- 原行为是双层硬拦：前端 `generateBlockReason` 禁用按钮 + 后端 `emit.generate` 抛 EmitError（"有一步不唯一就整体拒绝"），20 步里 1 步坏就全废。
- 现在改成「降级生成」：
  1. `locators.best_effort(framework, counted)`：取目标框架下 `count > 0` 且 count 最小的候选（同 count 比语义优先级）。
  2. `session._count(frame, specs, mark)`：录制时算 index。**做法**：recorder.js 在 `snap()` 里给目标元素打临时属性 `data-autocase-target=<随机>`（`snap._mark`），Python 用 `locator.evaluate_all(FIND_INDEX_JS, mark)` 在页面里 `findIndex`，算完 `CLEAR_MARK_JS` 摘掉。Playwright 语义选择器的内部排序拿不到，这是唯一可行路径。实测 3 个同名按钮 → index=1 正确、标记清理干净、找不到返回 -1。
  3. `emit._locator_info()` 返回 `{locator, matches, nth, mode}`；提示词每步带 `match_count` / `nth` / `candidates`（最多 5 条），并加了 PROMPT_RULES 让模型写 `.nth(n)`、没有 nth 就 `.first` + 注释。
  4. 只有「一条候选都命不中」才拒绝（错误前缀 `missing:`），因为那种情况写不出任何定位。
- `_revalidate_all` 复核时按 desc 把旧 index 带回来（复核时临时标记早没了，不带就丢降级信息）。

## 定位投影覆盖对齐 + 不变量测试（第二批第一刀）

- 问题：`build_specs()` 的 RF 组门槛写死（`tag in ('button','a')` 才出文本 xpath、`tag=='input'` 才出 placeholder），导致 `div role=button` / `li` / 图标按钮 / `data-testid` 的 span 全部只剩 `rf_css`。快照里明明有 role/aria-label/testid，只是没投影。实测 8 种常见元素里 4 种 RF 只有结构定位 → 「换框架」= 换定位质量。
- 改法（纯 locators.py）：RF 组新增 `rf_testid` / `rf_aria` / `rf_label` 三种 kind，`RF_PREFERENCE` 改为 `rf_testid > rf_id > rf_name > rf_aria > rf_label > rf_xpath > rf_css`（前端 `RF_ORDER` 同步）。投影项：`//*[@data-testid=..]`、`//*[@id=..]`、`//*[@name=..]`、`//*[@aria-label=..]`、`//*[@id=//label[normalize-space(.)=..]/@for]` 与 `//label[..]//*[self::input or self::textarea or self::select]`（两条，命中 0 的自然被跳过）、`//*[@placeholder=..]`、`//*[@role=R][normalize-space(.)=T]`（仅显式 role）、`//tag[normalize-space(.)=T]`（TEXT_TAGS 白名单，故意不含 div，避免 `//div` 把祖先容器算进来）。
- recorder.js 的 `snap()` 新增 `aria_label` 与 `role_attr` 两个原始字段。**role_attr 必须单独存**：`role` 字段是显式 role 或隐式角色合并后的值，用它生成 `//*[@role=..]` 会对真实 `<button>` 生成命中 0 条的候选。
- 新增 `backend/test_recording_locator_parity.py`（不变量测试）：真浏览器 + fixture 页面，12 种元素上断言 ——① 两边都有 count==1 的候选；② 两边选中的候选命中的 data-idx 必须正好是目标；③ 有语义信号时 RF 不许落到 rf_css；④ RF 组任何「恰好唯一」的候选都不许指错元素。另有重复按钮用例断言两边一致回退到结构定位。
- 实测：8 种元素 RF 组 `rf_css` 兜底 4/8 → 0/8；后端 71 项测试全过；真实录制流程复测（div role=button / testid span）新候选 count=1，`rf_testid` / `rf_xpath` 排到 RF 组首位。
