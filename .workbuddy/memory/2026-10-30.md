# 2026-10-30 全站深浅色

用户：「现在基本页面很多白色，我想在首页配置按钮旁边加一个深浅色切换按钮，出个方案让我选择」。
选定：全站双主题 / 夜墨质感 / 单键切换。

## 做了什么

### 主题骨架
- `styles/tokens.css` 拆成四组双值：表面（`--bg-page/-card/-sunken/-stage/-raised/-hover/-active/-code`）、
  文字（`--ink/-ink-2/-muted/-faint/-inverse`）、线（`--line/-line-soft/-line-faint/-line-field/-line-ctl`）、
  语义（`--accent/-hover/-soft/-soft-hover/-ink/-line`，`--danger*`、`--ok*`、`--warn*`）。
  另加 `--scrim / --focus-ring / --loading-mask / --scroll-thumb / --shadow-dialog / --shadow-primary`。
- `[data-theme="dark"]` = 夜墨：页 #12161d、卡 #191e27、淡底 #20262f、画布 #1c222b、浮层 #1e242d，
  文字 #e6eaf2 / #c3cbd8 / #8b95a6 / #66707f，主蓝提到 #0a84ff（暗底上 #0071e3 会发闷）。
- `index.html` 加同步内联脚本按 `ac-theme` 先定主题（不闪白）+ `meta theme-color`。
- `composables/useTheme.js`：同时设 `data-theme` 和 `.dark`；没存过跟随系统，切过就听用户的
  （系统监听仍挂着，回调里再查一次 localStorage）。
- `main.js` 引 `element-plus/theme-chalk/dark/css-vars.css`。
- `tokens.css` 里接管 `--el-*`（`:root, html.dark`）：主色九档用 `color-mix` 从 `--accent` 推，
  背景/文字/填充/描边全部指向 token。
- `App.vue`：顶栏右侧 `.head-actions` 放「日/月」+「设置」两颗 30px 图标按钮；`html, body` 也上底色。

### 全站字面量收口（约 640 处）
- `App.vue` / `buttons.css` / `list-page.css` / `forms.css` / `dialog.css` 全部换 token。
- `Settings`（9）、`AutomationRecords`（7）、`RecordingRecords`（14）、`Scripts`（34）、
  `Upload`（66）、`AutomationGenerationDetail`（78）、`PathPickerDialog`（39）逐处替换。
- `Recording.vue` 421 处：按「属性 → 角色」建显式色表（background/color/border 三张 dict），
  用正则按声明匹配替换 386 处，剩下的 19 处是深色面板上的白字/图片浮层，保留。

## 坑
- HLS 饱和度判色相不可靠：浅灰带 5% 蓝调时 s 能到 0.25，会把 `#f2f4f7` 判成蓝、整片淡灰变淡蓝。
  最后放弃启发式，改用显式色表（一次写清 110 个色值的归属，后续加页面照抄）。
- Element 的 `html.dark`（0,1,1）压得过 `:root`（0,1,0），所以映射块必须写成 `:root, html.dark`。
- 不接管 `--el-color-primary-light-9`，暗色下拉的选中行会变成褐黄（Element 用 primary 和背景 mix 出来的）。
- 暗色下拉浮层透明到看不清层次：`--el-bg-color-overlay` 要单独给 `--bg-raised`。
- `el-message` 默认拿 `--el-color-*-light-9` 当底，暗色下是一片半透明绿/黄飘在内容上；
  改成 `--bg-raised` + 细边，只让图标带语义色。
- 白底原型图在暗色里像灯箱：`[data-theme="dark"] .dlg-stage img` 等加 1px 白 12% 描边。
- 暗色日志面板 `#12161d` 和页面同色会糊：统一走 `--bg-code`（暗色 #0b0f14）。

## 首页动效（方案 D：A 阶梯入场 + C 路由切换）
- 新增 `frontend/src/styles/motion.css`（`main.js` 最后引入），只做两件事：
  首页首帧四组元素 70ms 错峰淡入上移 7px / 500ms；路由淡入 180ms + 内容区顶边 1px 蓝线 520ms。

  `from.name` 为空（首次进入）、或只有 query 变化时不扫线。`.el-main` 加 `position: relative` 当线的定位父级。
- `main.js` 改 `router.isReady().then(() => app.mount('#app'))`：否则首帧白拿一次路由淡入，和入场叠在一起。
- 顺带：`scrollBehavior` 换页回顶（savedPosition 优先），末尾加 `/:pathMatch(.*)*` 回落首页（原来地址打错只剩一条顶栏）。

## 修正：「No tests found」不是跑失败

用户在 midscene-ui-test 手跑生成的 `tests\ai-chat\ai-login-success.spec.ts` 报 No tests found。
根因不在用例：Playwright 的 CLI 路径参数走 minimatch，**`\` 是转义符**，
`tests\ai-chat\x.spec.ts` 会被吃成 `**/testsai-chatax.spec.ts`，一条都匹配不到。正斜杠正常。
用户那条用例本身 1 passed / 4.9s。我们的 `run_playwright` 早已 `.replace('\','/')`，不受影响
（实测：反斜杠入参 → 1 passed）。

顺带修掉一处误判：`run_playwright` 原来把「0 个用例被收集」当成 `ran=True, ok=False`，
会把它丢进 `_run_with_repair` —— emitter 没有 bash，只能盲改一个从未执行过的文件。
现在 `collected == 0` 且顶层错误含 `No tests found` → `ran=False` + 具体原因
（文件不存在 / 没有 test() 用例 / 不在 testDir 或被 testIgnore 排除）。
**文件加载失败（语法、import）必须继续算失败**，否则真错误会被藏起来——有专门一条测试锁住这个区分。

## 面板窗口「滚不动」（split 兜底布局，用户录制时踩到）

反馈原话：「假如访问的是不支持嵌入的页面，你这个工具栏是不是缺少滚轮啊，我现在在录制的时候发现滚不动」。

- 根因：`.recording-page.is-panel` 这层是 flex 列，但它的子节点 `.page-col` 没写 flex 规则
  （嵌入模式有 `.is-embed .page-col`、独立整页有 `:not(.is-panel):not(.is-embed) .page-col`，
  只有 split 的独立面板窗口漏了）。于是 `.page-col` 保持块级、`min-height:auto`，
  下面 `.recording-body / .main-layout / .steps-card / .el-card__body` 四层 `flex:1; min-height:0`
  全都无处可依，`.el-card__body` 上的 `overflow-y:auto` 也就不生效——卡片直接长到 1864px，
  再被 `#app.is-panel-mode .el-main{height:100vh;overflow:hidden}` 裁掉。
  表现正是「没有滚动条、底下的步骤既看不见也点不到」。
- 修：一条规则，`frontend/src/views/Recording.vue` 面板段
  `.recording-page.is-panel .page-col { flex:1; min-height:0; display:flex; flex-direction:column }`。
- 验证（600×900，16 步假会话）：colH 1951 → 878；bodyClient 791 < bodyScroll 1864；
  滚轮打在工具栏 / 步骤行 / 时间线上都滚到 500；用 `!important` 把 page-col 还原成块级，
  scrollTop 回到 0，复现原状。
- 回归：嵌入模式（1600×900）client 773 / scroll 1648 可滚、独立整页 colH 800 可滚、
  面板里展开「配置」后 config 460 + steps 326，`docScroll` 仍是 900。`npm run build` 通过。
- 两个验证时踩的坑：
  1. 冷启动幕布 `#ac-boot`（z-index 4000）会盖住整页，不等它揭完就用 `elementFromPoint` / 滚轮，
     量到的全是幕布——第一轮「滚轮无效」是假结论。验收脚本里直接 `remove()` 掉它。
  2. `page.route('**/api/**')` 会把 `/src/api/index.js` 也拦下来，Vite 的模块请求收到 JSON 就白屏，
     必须按 `urlparse(url).path.startswith('/api/')` 精确拦。
- 顺带确认：起一个临时 dev server 做验证时，用户自己那个只监听 `::1:5173`，
  Vite 会静默换到 5174（临时实例用完要关掉，别留第二个）。
