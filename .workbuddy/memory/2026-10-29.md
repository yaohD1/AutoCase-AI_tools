## 录制配置页重做（风格定为「静物」：只读摘要 + 点开就地编辑）

用户先反馈前端「不够精致、不够有创意」，要求先只改录制配置页并定风格。
给了三个方向（A 启动台 / B 蓝图 / C 静物）并各配一张示意；用户选 **C 静物** +
**字段默认只读、点击就地改**。

### 结论性的设计取向
- 不做「深色地址栏主视觉」那一套（A），也不把配置拆成编号流程（B），
  保留原字段顺序，只改**材质与层级**：下划线输入、分段选择、更大留白、去装饰。
- 页面里只允许一个重色块：主行动「开始录制」。其它一律低对比。

### 具体改动（仅 frontend/src/views/Recording.vue）
- 配置卡原本是 `el-form` + 6 个常驻输入框（400px 栏里像注册表单），全部拆掉，
  改成 `.cfg-field > .cfg-label + .cfg-view(值) / .cfg-input(编辑态)`。
- 新增 `cfgEditing` 单值状态 + `beginEdit/endEdit/setEditRef`：同一时刻只有一行展开；
  `await nextTick()` 后再 `focus()`（el-input 挂载前 focus 会打在旧 DOM 上）。
- 工作区**不提供手填**（只能在根目录里挑），行设为 `is-static`：光标和 hover 都不假装可编辑。
- 框架从 el-select 换成两段式 `cfg-seg`（只有两个取值，少一次点击且当前值常显）。
- 「高级：Python 解释器」折成一行，右侧直接显示当前值。
- 主行动从工具栏搬到配置卡底部（`cfg-foot`，`margin-top:auto` 贴底）。
  工具栏的「开始」只在 `steps.length || compactMode` 时出现，避免首屏两个蓝按钮。
- 首屏（`session` 为空）隐藏整排禁用工具栏、隐藏生成卡；步骤空态从一条虚线改成
  居中的两行说明。

### 两个踩到的坑
1. 「开始」改成条件渲染后，紧随其后的「停止」是 `v-else`，首屏直接显示成**停止**。
   改为 `v-else-if="isRecording"`。
2. 只读行 32px、编辑行 44px，切换时下面的行会跳 14px。给 `.cfg-input/.cfg-select`
   也定 32px 后两者一致（实测均为 63px 的 field 高）。

### 视觉 token（本页 scope，挂在 .config-card 上，不外溢）
ink #15181d / muted #8d97a6 / line rgba(0,0,0,.28) / hairline rgba(0,0,0,.06) /
accent #0071e3（沿用全局主色，避免与其它页打架）/ 路径一律等宽字体。

### 验证
前端 build 通过；用 Playwright 在 1440×900、1280×800、640×900（panel 模式）三个尺寸
截图核对，控制台无报错；实测点行→输入框聚焦→Enter 收起→值已更新。

### 踩坑：el-select 的选中值也在 placeholder 节点里
Element Plus 2.4 里 `.el-select__placeholder` 同时承担「占位」和「已选值」：
只有无值时才挂 `.is-transparent`。所以颜色必须写两条——
`.el-select__placeholder { color: ink }` + `.el-select__placeholder.is-transparent { color: faint }`。
只写后者会让**选中后值一直是占位灰**（第一版就是这个错，截图看像淡蓝）。

### 聚焦线不用蓝
选中模型后焦点仍在 select 上，蓝色下划线常驻会被误读成"这个字段还没填完"。
改为 focus/hover 都是 `rgba(0,0,0,.28)`；蓝色只留给主按钮。
