## 修复：工作区输入框「浏览 / 检测」按钮重叠

- 原因：Element Plus 对 `.el-input-group__append .el-button` 设了 `flex:1; margin:0 -20px`，append 里放两个按钮就会互相叠压。
- 解决：`Recording.vue` 里把两个按钮包进 `.append-group`，并用 `:deep(.el-input-group__append) .append-group .el-button` 覆盖为 `flex:0 0 auto; margin:0` + `gap:6px`。
- 实测两按钮盒子 x=725/800 不再重叠；`npm run build` 通过。
- 排查手段备忘：本地验证用 `PORT=5055` 起后端 + 临时 vite 配置（proxy 指 5055，端口 5199）访问要用 `localhost` 而不是 `127.0.0.1`（本机 127.0.0.1 会被上层代理拦成 502）。
- 追加：两按钮改为同高 26px、居中、中间加 `.append-sep` 竖线（1px × 14px），并给按钮加 hover 高亮；实测两按钮 top/高度一致、文字中心相差 1px（子像素），真实点击两个按钮分别打开弹窗/触发检测。
